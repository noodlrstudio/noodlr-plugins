# WAM 2 plugin starter

This minimal gain effect demonstrates the WAM surface Noodlr's curated host
uses: an audio node, MIDI event scheduling, JSON state, and a native GUI.

```sh
npm install
npm run check
```

Treat `src/index.ts` as the reviewed bundle entry point. A repository submission
vendors the built output under a versioned path, records every SHA-256 checksum,
and adds its manifest to the allowlisted catalog. Noodlr creates the WAM group,
owns graph connections, and calls GUI and node teardown.

See `docs/plugin-sdk/audio-plugins.md` and
`docs/plugin-sdk/submitting.md` before submitting.
